# Instruções para Claude Code

Leia e siga integralmente [AGENTS.md](AGENTS.md). Ele é a fonte única das regras de trabalho deste repositório.

Antes de planejar ou editar:

1. Leia [docs/AI_CONTEXT.md](docs/AI_CONTEXT.md).
2. Leia [docs/AI_HANDOFF.md](docs/AI_HANDOFF.md).
3. Confirme a pasta, a branch e o estado do Git.

Ao transferir trabalho de volta para o Codex ou encerrar uma tarefa incompleta, atualize o handoff conforme as regras de `AGENTS.md`.
